# Matchday images

Drop card artwork here. A file at `public/images/matchday/city-porto.jpg` is served
at `/images/matchday/city-porto.jpg`, which is what goes in a post's frontmatter:

```
heroImage: /images/matchday/city-porto.jpg
```

Competition logos live in `../competitions/` and are wired up in the `COMPETITIONS`
map in `src/lib/matchday.ts`.

Guidelines: landscape, roughly 1600x1000, JPG for photos and SVG/PNG for logos,
under ~500KB each.
